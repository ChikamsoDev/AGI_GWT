The Global Workspace is the central place where all modules communicate.

It holds the information that is currently in focus, along with any information that has been submitted by modules and is waiting to be considered.

Modules send messages to the workspace whenever they discover something important. Each message should include the information itself and some indication of how important or urgent it is.

The workspace compares all submitted messages and chooses the one with the highest priority. This message becomes the current focus of the system.

Once a winner has been chosen, the workspace broadcasts it to every module connected to the system.

Each module receives the broadcast and can decide how to react. For example, a memory module might search for related memories, a reasoning module might analyze the information, and a planning module might decide whether an action should be taken.

Because every module receives the same broadcast, they can coordinate their behavior around the same piece of information instead of working independently.

{
  "source": "vision",
  "content": <the actual data — SceneGraph, text, whatever>,
  "priority": 0.87,        ← confidence score or attention score
  "prediction_error": 0.3, ← how surprised the module was
  "timestamp": 1042,
  "type": "perception"     ← so receivers know what kind of message this is
}
